# 1.0 Proyecto: Módulo de analítica de retención

**Descripción:** Desarrollo de un dashboard de KPIs de retención para un SaaS universitario.

## 1.1 Planeación y análisis

- **1.1.1** Identificar las necesidades del usuario.
- **1.1.2** Definir los KPIs de retención.
- **1.1.3** Establecer los requisitos del módulo.
- **1.1.4** Organizar las tareas y el calendario.

## 1.2 Diseño del módulo

- **1.2.1** Diseñar las pantallas del dashboard.
- **1.2.2** Diseñar la estructura de los datos.
- **1.2.3** Definir las gráficas y filtros.
- **1.2.4** Definir los permisos de acceso.

## 1.3 Desarrollo del módulo

- **1.3.1** Obtener y preparar los datos.
- **1.3.2** Implementar el cálculo de KPIs.
- **1.3.3** Crear las tarjetas y gráficas.
- **1.3.4** Implementar filtros y consultas.

## 1.4 Pruebas y correcciones

- **1.4.1** Probar el cálculo de los KPIs.
- **1.4.2** Verificar las gráficas y filtros.
- **1.4.3** Corregir errores encontrados.

## 1.5 Documentación y entrega

- **1.5.1** Elaborar una guía breve de uso.
- **1.5.2** Documentar los KPIs y sus fórmulas.
- **1.5.3** Presentar el dashboard final.

## CPM y PERT

### Ruta crítica propuesta (CPM)

Requisitos → Diseño de datos → Preparación de datos → Cálculo de KPIs → Dashboard integrado → Pruebas → Entrega.

### Estimación PERT

Para cada actividad se estiman tres duraciones:

- **O:** Duración optimista.
- **M:** Duración más probable.
- **P:** Duración pesimista.

La duración esperada se calcula con la siguiente fórmula:

\[
TE = \frac{O + 4M + P}{6}
\]
