1.0 Proyecto ControlLibro
Desarrollo del sistema de gestión bibliotecaria

1.1. Planeación y análisis
- 1.1.1. Identificar las necesidades de la biblioteca.
- 1.1.2. Recopilar información mediante entrevistas y observación.
- 1.1.3. Definir los requisitos del sistema.
- 1.1.4. Organizar las tareas y el calendario de trabajo.

1.2. Diseño del sistema
- 1.2.1. Diseñar las pantallas de la aplicación.
- 1.2.2. Diseñar la estructura de la base de datos.
- 1.2.3. Diseñar el flujo de préstamos y devoluciones.
- 1.2.4. Definir los permisos de acceso.

1.3. Desarrollo de la aplicación
- 1.3.1. Crear el catálogo de libros.
- 1.3.2. Crear el registro y consulta de usuarios.
- 1.3.3. Implementar el módulo de préstamos.
- 1.3.4. Implementar el módulo de devoluciones.
- 1.3.5. Implementar el control de vencimientos.
- 1.3.6. Crear los reportes de actividad.

1.4. Base de datos
- 1.4.1. Crear las tablas necesarias.
- 1.4.2. Relacionar libros, usuarios y préstamos.
- 1.4.3. Implementar las operaciones de consulta y actualización.
- 1.4.4. Verificar la integridad de los datos.

1.5. Pruebas y correcciones
- 1.5.1. Probar el registro y búsqueda de libros.
- 1.5.2. Probar el registro de usuarios.
- 1.5.3. Probar préstamos y devoluciones.
- 1.5.4. Verificar avisos de vencimiento y reportes.
- 1.5.5. Corregir errores detectados.

1.6. Documentación y entrega
- 1.6.1. Elaborar el manual de usuario.
- 1.6.2. Documentar la instalación y configuración.
- 1.6.3. Integrar las evidencias del proyecto.
- 1.6.4. Presentar la aplicación final.

Diccionario de trabajo de la WBS
El diccionario describe qué se realizará en cada paquete de trabajo, qué resultado debe entregarse y cómo se comprobará que está terminado.
| Código | Paquete de trabajo | Descripción | Entregable o criterio de aceptación |
|---|---|---|---|
| 1.1.1 | Identificación de necesidades | Reconocer los problemas actuales del registro bibliotecario. | Lista de necesidades documentadas. |
| 1.1.2 | Recopilación de información | Aplicar entrevistas, cuestionarios y observación. | Instrumentos y resultados recopilados. |
| 1.1.3 | Requisitos | Definir las funciones que tendrá el sistema. | Documento de requisitos aprobado por el equipo. |
| 1.1.4 | Calendario | Distribuir actividades y fechas de entrega. | Cronograma del proyecto. |
| 1.2.1 | Diseño de pantallas | Crear una propuesta visual para las ventanas del programa. | Bocetos o prototipos de las pantallas. |
| 1.2.2 | Diseño de base de datos | Definir tablas, campos y relaciones. | Diagrama o esquema de la base de datos. |
| 1.2.3 | Flujo de préstamos | Establecer los pasos para prestar y recibir libros. | Flujo de proceso definido. |
| 1.2.4 | Permisos de acceso | Definir quién puede consultar o modificar información. | Reglas de acceso documentadas. |
| 1.3.1 | Catálogo de libros | Permitir registrar, buscar, consultar y actualizar libros. | Módulo funcional del catálogo. |
| 1.3.2 | Usuarios | Registrar y consultar a los usuarios de la biblioteca. | Módulo funcional de usuarios. |
| 1.3.3 | Préstamos | Registrar qué libro se presta, a quién y en qué fecha. | Préstamos guardados correctamente. |
| 1.3.4 | Devoluciones | Registrar la devolución y actualizar la disponibilidad del libro. | Devolución reflejada correctamente. |
| 1.3.5 | Vencimientos | Identificar préstamos que superaron la fecha de entrega. | Lista o aviso de préstamos vencidos. |
| 1.3.6 | Reportes | Mostrar información de préstamos, devoluciones y actividad. | Reportes consultables. |
| 1.4.1 | Tablas | Crear las estructuras para guardar la información. | Tablas creadas en la base de datos. |
| 1.4.2 | Relaciones | Conectar los registros de libros, usuarios y préstamos. | Relaciones verificadas. |
| 1.4.3 | Consultas y actualizaciones | Permitir insertar, buscar y modificar registros. | Operaciones comprobadas. |
| 1.4.4 | Integridad | Evitar registros incompletos o inconsistentes. | Pruebas de integridad satisfactorias. |
| 1.5.1–1.5.4 | Pruebas funcionales | Revisar que cada módulo cumpla su función. | Casos de prueba ejecutados y resultados registrados. |
| 1.5.5 | Corrección de errores | Resolver los problemas encontrados durante las pruebas. | Errores corregidos y verificados. |
| 1.6.1 | Manual de usuario | Explicar cómo utilizar las funciones del sistema. | Manual con instrucciones claras. |
| 1.6.2 | Instalación | Documentar los requisitos y pasos para ejecutar la aplicación. | Guía de instalación. |
| 1.6.3 | Evidencias | Reunir capturas, documentos y resultados del proyecto. | Carpeta de evidencias organizada. |
| 1.6.4 | Entrega final | Preparar la versión terminada y su presentación. | Aplicación y documentación entregadas. |
